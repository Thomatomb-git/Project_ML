## 1. Purpose
The final project provides students with an opportunity to integrate theoretical understanding and practical skills in Machine Learning. Students are required to design, implement, deploy, and evaluate a machine learning solution that addresses a real-world problem.

This project emphasizes an end-to-end classical machine learning pipeline, including data understanding, model development, system deployment, and evaluation through real user interaction.

## 2. Learning Outcomes (LOs)
Upon successful completion of this project, students will be able to:
* **LO1:** Explain fundamental machine learning concepts and challenges.
* **LO2:** Analyze datasets and apply regression, classification, or clustering techniques appropriately.
* **LO3:** Implement, deploy, and evaluate a machine learning system based on real user interaction and feedback.

### Mapping of Deliverables to Learning Outcomes

| Deliverable | Aligned Learning Outcomes |
| :--- | :--- |
| Machine Learning Model & Source Code | LO1, LO2 |
| Deployed Application | LO2, LO3 |

## 3. Technical Requirements & Constraints

### Suggested Project Themes
* Regression-based predictive systems
* Classification-based decision support systems
* Recommender systems with user interaction
* Clustering-based user segmentation tools
* End-to-end machine learning applications with user feedback loop

### 🚫 Methodological Constraints
* **Allowed:** Only classical machine learning methods are allowed (linear models, tree-based models, SVM, clustering).
* **Strictly Prohibited:** Deep learning approaches are strictly **not allowed** in this course.

### Technical Notes
* **Programming Language:** Python
* **Libraries:** NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn
* **Deployment Frameworks (Mandatory):** Flask, FastAPI, or Streamlit
* **Version Control:** Git (mandatory)

### Deployment Requirement (Mandatory)
* The machine learning model must be deployed as a usable application.
* Deployment may be web-based or API-based.
* The deployed system must:
  1. Accept user input
  2. Execute the trained model
  3. Produce clear and interpretable output
* Accessibility may be via local demo, shared access link, or recorded live demonstration.

### Real User Testing Requirement (Mandatory)
* Minimum **5 real users** (who are not part of the project team).
* Students must define:
  * Anonymized user background
  * Usage scenario
  * Usability and usefulness feedback
* Collect quantitative (rating/Likert) and qualitative feedback.
* Results must be analyzed and presented in the PPT.
